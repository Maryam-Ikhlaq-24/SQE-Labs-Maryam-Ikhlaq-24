This lab tests the authentication module `auth.py` (a library management system) using white-box testing. Coverage.py measures which statements and branches the tests run, and allpairspy generates a pairwise covering array for the book search form.

## Project structure

```
week7/
├── auth.py                  # Module under test (from lab Appendix B)
├── pairwise_check.py        # Pairwise test case generator and checker
├── pytest.ini               # pytest configuration
├── .coveragerc              # Coverage.py configuration (branch coverage on)
├── analysis.md              # Baseline, gap analysis, final coverage
├── screenshots/             # Coverage and test run screenshots
└── tests/
    ├── conftest.py          # Autouse fixture: fresh store for every test
    ├── test_auth.py         # Original tests TC-001 to TC-007 (from earlier labs)
    └── test_auth_new.py     # Tests written in Lab 7 (27 tests in total)
```

## Setup

```powershell
python -m pip install coverage pytest allpairspy
```

Coverage.py 7.6 or later is required.

## Running the tests

From the `week7` folder:

```powershell
python -m pytest -v
```

## Measuring coverage

```powershell
python -m coverage run -m pytest
python -m coverage report -m
python -m coverage html
python -m coverage report --fail-under=80
```

`--fail-under` exits with code 2 if the total is below the threshold, and 0 if it passes.

## Results

| Stage | Tests | Total coverage |
|---|---|---|
| Original tests (`test_auth.py`) | 7 | 55% |
| After guided tests (Experiment C) | 17 | 75% |
| Final suite | 27 | 90% |

The final suite reaches 90% statement and branch coverage. The remaining missing lines are helper functions and "not found" paths, explained in `analysis.md`.

## Pairwise design

`pairwise_check.py` generates a 2-way covering array for four parameters (query type, filter, sort order, page size). The full set has 81 combinations. The generated array has 9 cases, covers all 54 required pairs, and reduces the test count by 9x.

```powershell
python pairwise_check.py
```
